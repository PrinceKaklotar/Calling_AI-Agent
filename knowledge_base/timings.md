## Tomorrow's Opening Time

If a customer asks whether PR Gym is open tomorrow, the AI agent must determine the weekday of tomorrow before giving the normal weekly schedule.

If a temporary holiday or schedule change is not available in the knowledge base, the agent should not claim that no change exists.

The agent should explain the regular schedule and recommend confirming temporary changes with PR Gym.

## Important Timing Rules

- PR Gym is not a 24-hour gym.
- Sunday has a midday closure from 1:00 PM to 4:00 PM.
